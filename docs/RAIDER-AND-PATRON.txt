================================================================================
  THE ONE BLOCKER - THE FIGURE ON THE PLINTH
================================================================================

  The knight in the Raider mockup is a RENDER. Two models were supplied:
  the hooded skull and the fiery logo. Both are already live on the landing.
  There is no knight, and there are three classes to cover.

  WHY THE GAME SPRITES CANNOT STAND IN

    public/art/raider/*.png     24 files, 256 x 256 each

      warrior-6.png    solid pixels   364   of 65,536
      knight-6.png     solid pixels   435   of 65,536
      fighter-6.png    solid pixels   280   of 65,536

    +----------------------------+
    | 256 x 256 frame            |   about 20 x 20 worth of real
    |                            |   pixels. the rest is empty or
    |             .              |   81 percent transparent. these
    |                            |   are downsampled renders from
    +----------------------------+   another pipeline.

  WHAT WAS PREPARED INSTEAD

    Enhancement/for-modelling/

      warrior-render.png      1080 x 2100   the mockup render, cropped
                                            head to feet. best input.
      knight-from-mockup.png  1020 x 1410   wider, with plinth and floor.
                                            keep as a style reference.
      warrior-ingame.png      1080 x 1500   the three classes as the game
      knight-ingame.png       1080 x 1500   actually draws them. flat grey
      fighter-ingame.png      1080 x 1500   ground, front on, whole figure.

  WHAT TO ASK A CONVERTER FOR

    format        .glb
    pose          as shown, arms down, front on
    scale         does not matter, it is normalised by bounding box
    polycount     do not worry
    textures      baked colour is fine
    size          send whatever comes out, 50 to 100 MB is fine

  DO NOT OPTIMISE BEFORE SENDING. The pipeline is already proven:

      demonic skull mask    53.5 MB  ->  0.38 MB    99.3 percent off
      fiery logo            55.2 MB  ->  0.63 MB    98.9 percent off

      decimate (meshopt) -> Draco compress -> WebP textures

  WHEN THE MODELS COME BACK

    1  compress each the same way, about 0.4 MB each
    2  drop into public/art/champions/
    3  swap the plinth's canvas champion for a 3D one, lit by the SAME
       rig built for the skull on the landing:

           key from below-front    #ff6a55
           cheek fill right        #b44e4c
           rim behind              #600110

       so the plinth and the landing agree
    4  gothic hall goes in behind it
    5  the class switcher rotates between the three
